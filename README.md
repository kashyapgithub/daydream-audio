# Daydream Audio

> *Sound the way you remember it.*

A plain-English Android audio EQ, virtualizer, and restoration suite — built for people who don't know what "3.2kHz" means, but know their old recordings sound thin, muddy, hissy, or flat.

## Docs

- [Product Requirements Document](docs/PRD.md) — full spec: features, DSP algorithm specifications, cross-Android-version strategy, permission architecture, and the "Liquid Glass" UI/UX design system with build-ready design tokens.

## Status

Pre-development — this repo currently holds the PRD only. No code yet.
